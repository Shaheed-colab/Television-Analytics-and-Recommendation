# Title : Television Market Analysis, Price Prediction & Recommendation System
# Project Overview
This project is an end-to-end Data Science capstone that focuses on analyzing the television market using web-scraped e-commerce data. It includes data collection, cleaning, exploratory data analysis, machine learning modeling, and a recommendation system.
#### Main Goal : The goal is to help users understand TV market trends, predict TV prices based on specifications, and recommend the best TVs based on user preferences.
# Objectives
1. Scrape television data from e-commerce websites
2. Perform data cleaning and preprocessing
3. Conduct exploratory data analysis (EDA)
4. Detect and handle outliers and missing values
5. Engineer meaningful features
6. Build a price prediction model
7. Develop a recommendation system
8. Deploy the project as an interactive application
# Technologies Used
* Python 
* Pandas, NumPy
* Matplotlib, Seaborn
* Scikit-learn
* Selenium / BeautifulSoup (for web scraping)
* Streamlit (for deployment)
# Project Workflow
* Data Collection (Web Scraping)
* Data Cleaning & Preprocessing
* Feature Engineering
* Exploratory Data Analysis (EDA)
* Outlier Detection
* Missing Value Handling
* Feature Selection
* Model Building (Price Prediction)
* Recommendation System
* Deployment (Streamlit App)
# Dataset Features
* Brand
* Model Name
* Price
* Rating
* Screen Size
* Resolution
* Display Type (LED / OLED / QLED)
* Smart TV (Yes/No)
* Operating System
* Warranty
# Machine Learning Models
* Linear Regression
* Random Forest Regressor
* XGBoost (optional)
# Evaluation Metrics
* MAE (Mean Absolute Error)
* RMSE (Root Mean Squared Error)
* R² Score
# Recommendation System
A content-based recommendation system is built using similarity between TV features such as:

* Screen size
* Price
* Brand
* Display type
* Resolution

Users can input preferences and get recommended TVs.
# Deployment
The project is deployed using Streamlit, allowing users to:

* Explore data insights
* Predict TV prices
* Get TV recommendations interactively
